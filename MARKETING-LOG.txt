1. **REC-20261030-01: Unprivilegiertes MSIX / Winget-Packaging**
   - *Problem:* Das aktuelle Installationsskript `install-desktop-shortcut.ps1` arbeitet rein auf Dateiebene im Benutzerprofil. Für Unternehmens-Deployments oder Nutzer ohne PowerShell-Skriptausführung wäre eine offizielle Winget-Bereitstellung (`winget install dev-bricks.app-rotator`) ein erheblicher Usability-Gewinn.
   - *Empfehlung:* Bereitstellung eines unprivilegierten MSIX-Pakets (oder Sparse MSIX Manifests) über GitHub Actions Releases, das die Win32-Binärdateien ohne Administratorrechte kapselt und im Microsoft Community Repository registriert.

2. **REC-20261030-02: Optionale native Windows Toast-Benachrichtigungen (User Opt-In)**
   - *Problem:* Wenn der Rotator im Hintergrund eine Anwendung beendet und in die 2-minütige Abkühlpause wechselt, bemerkt der Anwender dies nur über das Tray-Icon oder die Fenster-Schließung.
   - *Empfehlung:* Einbindung optionaler Windows Desktop Toasts (z. B. via `winotify` oder PowerShell-Toast, standardmäßig deaktiviert zur Wahrung der Zero-Distraction-Garantie). Eine 30-Sekunden-Warnung ("Codex Desktop wird in 30 Sekunden pausiert") würde versehentlichen Datenverlust bei ungespeicherten Eingaben weiter minimieren.

3. **REC-20261030-03: Tkinter Dark Mode & Windows 11 Fluent Theme Styling**
   - *Problem:* Das native Tkinter-Fenster nutzt standardmäßig das klassische Windows-Standarddesign (heller Hintergrund). Bei Nutzern mit systemweitem Dark Mode entsteht ein visueller Bruch.
   - *Empfehlung:* Integration einer leichtgewichtigen, rein lokalen Tkinter-Dark-Theme-Unterstützung (z. B. via `sv-ttk` oder native `DwmSetWindowAttribute` API für die Titelleiste), die das systemweite Windows-Hell/Dunkel-Design automatisch adaptiert.

4. **REC-20261030-04: Hardware-Introspektion & VRAM-Einsparungs-Metrik**
   - *Problem:* Der tatsächliche Nutzen (freigegebener VRAM und RAM) wird derzeit nicht quantitativ im Tray angezeigt.
   - *Empfehlung:* Optionale Anbindung an das Geschwisterwerkzeug `system-explorer` (`ellmos-ai/system-explorer`), um beim Hover über das Tray-Icon die kumulierte VRAM-Freigabe (z. B. "Heute freigegeben: 38,4 GB VRAM") anzuzeigen.
