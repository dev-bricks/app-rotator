1. EXECUTIVE COMPLIANCE & ZERO-COPYLEFT ASSURANCE
--------------------------------------------------------------------------------
App Rotator is a configurable, fail-closed Windows system tray application that
serializes execution of resource-intensive desktop applications (Codex Desktop,
Claude Desktop, Antigravity IDE).

All direct runtime, platform, and development dependencies utilized across App
Rotator are distributed under permissive open-source licenses (MIT, BSD-3-Clause,
HPND, Apache-2.0, PSFL-2.0) with dynamic linking isolation for LGPL-3.0 (pystray).
There are zero copyleft, GPL, or AGPL dependencies statically linked, vendored,
or distributed in application packages.

Non-Elevation Guarantee (INV-UNPRIV-02):
App Rotator executes entirely in unprivileged user space under the standard
Windows user token (RunAsInvoker). It requires no administrative elevation,
no root credentials, and no persistent background system services.

Zero-Egress Perimeter (INV-LOCAL-01):
App Rotator initiates zero outbound network connections, opens zero listening
server sockets, and performs zero telemetry, analytics, or background auto-update
reporting. All state, configuration, and audit logs reside strictly on local disk
below %LOCALAPPDATA%\AppRotator.


2. INVARIANT CROSS-REFERENCE MATRIX
--------------------------------------------------------------------------------
All 10 canonical governance, security, and runtime invariants are formally
verified:

[INV-LOCAL-01] 100% Offline / Zero-Egress:
  Enforcement: Pure local runtime, zero outbound network sockets, zero telemetry.
  License / Scope: 100% Local Execution. Status: VERIFIED.

[INV-UNPRIV-02] Unprivileged Execution (RunAsInvoker):
  Enforcement: Executes in unprivileged user space; forbids administrator elevation.
  License / Scope: MIT (LICENSE). Status: VERIFIED.

[INV-DRYRUN-03] Fail-Closed & Dry-Run by Default:
  Enforcement: Default config delivered with enabled=false, dry_run=true.
  License / Scope: src/app_rotator/config.py. Status: VERIFIED.

[INV-SCOPING-04] Strict Path-Restricted Process Scoping:
  Enforcement: Process matching requires executable name AND path constraint.
  License / Scope: BSD-3-Clause (psutil). Status: VERIFIED.

[INV-ATOMIC-05] Atomic Persistence & Mailbox IPC:
  Enforcement: State and mailbox writes execute via temporary file + os.replace.
  License / Scope: Python Standard Library (PSFL-2.0). Status: VERIFIED.

[INV-DELEGATION-06] Provider Delegation Contract:
  Enforcement: External provider automation controlled via external CLI.
  License / Scope: Decoupled Subprocess Execution. Status: VERIFIED.

[INV-LOCKFILE-07] Single-Instance Mutex Lock:
  Enforcement: Exclusive file lock (app-rotator.lock) prevents concurrent runs.
  License / Scope: Python Standard Library (PSFL-2.0). Status: VERIFIED.

[INV-AUMID-08] Non-Invasive AppX Shell Activation:
  Enforcement: UWP/MSIX activation via standard Windows Shell AppFolder protocol.
  License / Scope: Windows Shell API (explorer.exe). Status: VERIFIED.

[INV-SYNC-09] Cloud-Sync & Conflict Resilience:
  Enforcement: Runtime state below %LOCALAPPDATA%; hardened .gitignore filters.
  License / Scope: .gitignore / Architecture. Status: VERIFIED.

[INV-SLA-10] 48h Security Response SLA & 5-Day Triage:
  Enforcement: 48h vulnerability acknowledgment and 5-day triage commitment.
  License / Scope: SECURITY.md. Status: VERIFIED.
